# الموقع الجديد سيرفر Node على Render، والموقع الاحتياطي يفضل شغال

فورم التواصل وصفحة الإدارة محتاجين سيرفر، لأن المفتاح السري بتاع Supabase لازم يفضل على السيرفر ويستخدمه هو بس. عشان كده الموقع الجديد بيتنشر كـ Node web service على Render (الخطة المجانية)، مش static site. الهدف النهائي إنه يتنقل لـ Railway لما يبقى مضمون، فالكود بيتكتب Next.js عادي من غير أي حاجة خاصة بـ Render.

الموقع الاحتياطي (HTML على برانش `landing-html`، على Cloudflare وGitHub Pages) بيفضل شغال على طول من غير ما حد يلمسه، كنسخة احتياطية مستقرة، وفورمه بيبعت لنفس جدول Supabase. لينك العملاء بيتغير للجديد لما يبقى شغال تمام.

## Consequences

- الخطة المجانية على Render بتنيّم الموقع بعد 15 دقيقة من غير زيارات، وأول زائر بعدها بيستنى حوالي دقيقة. ده مقبول مؤقتاً لأن الموقع الاحتياطي موجود.
- أي تعديل في الكلام أو الأسعار بيظهر في الموقع الجديد بس، والموقع الاحتياطي بيفضل على حاله.
